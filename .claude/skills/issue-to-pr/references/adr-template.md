# ADR テンプレート

以下のテンプレートを使用して `docs/adr/YYYY-MM-DD-<slug>.md` に記録する。

---

```markdown
# <タイトル>

- **ステータス**: accepted
- **日付**: YYYY-MM-DD
- **Issue**: #N

## コンテキスト

何が問題で、なぜ判断が必要だったのか。

## 検討した選択肢

### 選択肢 A: <名前>

- 利点: ...
- 欠点: ...

### 選択肢 B: <名前>

- 利点: ...
- 欠点: ...

## 決定

選択肢 X を採用する。理由は...

## 影響

この決定により何が変わるか。トレードオフは何か。
```

---

## ファイル命名規則

- パス: `docs/adr/YYYY-MM-DD-<slug>.md`
- slug: 英語 kebab-case（例: `use-rag-engine`, `switch-to-firestore`）
- 日付: 判断日

## ステータスの種類

| ステータス | 意味                      |
| ---------- | ------------------------- |
| proposed   | 提案中（レビュー待ち）    |
| accepted   | 採用済み                  |
| superseded | 後続の ADR で置き換え済み |
| deprecated | 非推奨（廃止予定）        |
