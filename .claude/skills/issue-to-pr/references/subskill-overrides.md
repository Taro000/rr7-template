# サブスキルの既定を上書きする

| サブスキル                | 既定の挙動                                                 | このスキルでの上書き                                                                     |
| ------------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| superpowers:brainstorming | 設計成果物を `docs/superpowers/specs` に保存・自動コミット | 設計判断は ADR（`docs/adr`）として**承認後**保存。合意は plan 承認に集約。コミットしない |
| superpowers:writing-plans | 計画を `docs/superpowers/plans` に保存・自動コミット       | 計画は `docs/features` に**承認後**保存。コミットしない。plan mode 中は書かない          |
| tdd-implement             | main で作業・ブランチ作らない                              | Step 5 のブランチ上で実装（main では作業しない）。commit しない点は維持                  |
| requesting-code-review    | レビュー結果を報告して終わり                               | 軽微は自動修正→再レビュー(合格までループ)、設計級は停止して人へ。ロック済テスト不可触    |
| commit                    | ステージ済みのみ commit                                    | 直前に ADR・計画・実装を `git add -A` してから commit                                    |
