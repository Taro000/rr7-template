# サブスキルの既定を上書きする

| サブスキル                | 既定の挙動                                                   | このスキルでの上書き                                                                                                                                   |
| ------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| superpowers:writing-plans | 計画を `docs/superpowers/plans` に保存・自動コミット         | 計画は `docs/features` に**無人ゲート通過後**保存。コミットしない。不明点は人へ質問せず Step 2 の分岐で処理                                            |
| tdd-implement             | main で作業・ロック済みテスト修正/計画変更は AskUserQuestion | Step 5 のブランチ上で実装。AskUserQuestion は使わず無人フォールバック（SKILL.md Step 6）。テスト失敗は同一の失敗につき 3 回まで。commit しない点は維持 |
| requesting-code-review    | レビュー結果を報告して終わり                                 | 軽微は自動修正→再レビュー(合格までループ)、設計級は無人失敗プロトコルへ（draft PR ＋ コメント）。ロック済テスト不可触                                  |
| commit                    | ステージ済みのみ commit                                      | 直前に ADR・計画・実装を `git add -A` してから commit                                                                                                  |
| create-pr                 | push + PR 作成前に AskUserQuestion で同意                    | 合成時例外により省略（同意は Step 3 の無人ゲート通過に集約）                                                                                           |
